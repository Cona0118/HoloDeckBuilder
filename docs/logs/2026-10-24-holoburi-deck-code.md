# 2026-10-24 — 홀로부리 덱 코드 불러오기·내보내기 추가

- Event: Release
- Effective scope: 전체 사용자 — 덱 빌더(`/`).
  - 불러오기: 덱 선택 아래 줄에 「텍스트로 덱 불러오기」와 「홀로부리 코드로 불러오기」 버튼을
    나란히 두었다. 홀로부리 버튼은 코드를 붙여넣는 대화상자를 열고, 불러오면 새 덱이 활성 덱이 된다.
    클립보드 텍스트 불러오기도 `hocg1.` 코드가 있으면 코드로 불러온다. 우리에게 없는 카드는
    제외하고 매수를 알린다.
  - 내보내기: 데스크톱 하단 보조 액션 「홀로부리 코드」, 모바일 FAB 「홀로부리 코드 복사」가 활성 덱을
    홀로부리 덱 코드로 클립보드에 복사한다. 클립보드 권한이 없으면 코드를 직접 복사할 수 있는 창을
    띄운다.
  - 코드 형식은 홀로부리 프로덕션 번들을 역분석해 얻었다: `"hocg1." + base64url(UTF-8 JSON
    {n,o,m,c,a?})`.
  - 옐은 일러스트별 옐 번호(`hY0N-NNN`)로 주고받아 옐 일러스트 선택이 유지된다.
  - 일러스트는 카드당 1종이다. 같은 카드가 여러 일러스트로 나뉘어 있으면 매수가 가장 많은
    일러스트를 내보낸다.
  - 번호 없는 레어도 코드(`SR`, `UR`, `OUR`, `SEC`, `HR` 등)만 교환한다. 홀로부리의 번호 붙은
    코드(`SR_2`)는 자체 인쇄 순번이라 우리 파일 번호와 다른 그림을 가리킨다(이미지 대조로 확인:
    hBP03-044 `SR_2`). 그래서 번호 붙은 일러스트는 기본 일러스트로 둔다.
